## 코드에서 확인한 현재 동작

Flask 영상 업로드 → ffmpeg 프레임 추출 → 한국어 Tesseract OCR → 선택적 faster-whisper 음성 전사 → 예시 단어 목록 매칭 → 일부 문장의 Anthropic API 문맥 분석 구조다. URL 입력은 미구현이다. 이 인수 과정에서 실제 영상 실행이나 외부 AI 호출은 수행하지 않았다.

## 기존 요구사항과의 차이

1. 금지어 일치만으로 부당광고를 확정한다. 인용·부정·주의 문맥과 제품별 허용 범위를 확인해야 한다.
2. 단어가 없거나 추출 텍스트가 비어도 문제 없음으로 갈 수 있다. 미추출·부분 추출·검토 범위를 구분해야 한다.
3. 추출 모듈은 시간 정보를 갖지만 판정 결과에는 문제 장면의 타임코드를 연결하지 않는다.
4. 예시 사전은 완치·부작용 없음·최고·즉시 효과뿐이며 법적 근거는 예시 문자열이다.
5. 제품 분류·신고정보·성분/함량·인정 기능성·연구 적용성 대조는 구현되지 않았다.
6. AI 응답의 misleading 필드는 엄격한 boolean 검증 없이 bool()로 변환하고, JSON 파싱 실패 시 문자열 추측으로 판단한다.
7. 업로드 임시 경로에 사용자가 보낸 파일명을 직접 사용한다. 업로드 제한·고유 파일명·처리 후 보관 정책을 정해야 한다.
8. 기본 실행은 0.0.0.0 및 debug 활성이다. 로컬 실행과 배포 설정을 구분해야 한다.

## 보완 순서 제안

기존 Python/Flask 구조를 유지하고 먼저 판정 정확성과 근거 표시를 개선한다. 위반 의심/확인 필요/검토 범위 내 주요 의심 없음, 기존 17개 기준과 6개 서비스 유형, 타임코드와 출처, API 미설정·실패·빈 추출 처리를 우선한다. 이후 제품 기록과 인체시험을 입력·대조하는 흐름을 연결한다. 자동 웹 수집은 제품 식별과 자료 신뢰성 검토 후 별도 범위로 정한다.

다른 선택은 제품정보·연구 대조 입력 화면까지 한 번에 연결하는 것이다. 범위가 커지므로 데이터 출처, 자동조회 수준, 실제 영상 시험 환경을 먼저 결정해야 한다. 이 문서는 코드 인수 기록이며 기능 구현·검증 완료 보고가 아니다.
